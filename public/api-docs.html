NKB Developer REST API Reference

The NKB Manufacturing Corporation API enables external platforms, eCommerce stores (Shopify, WooCommerce), custom ERPs, and warehouse barcode scanners to programmatically sync product catalogs, submit purchase orders, track production deliveries, and retrieve real-time invoices.

Base Production URL: http://my.nkbmanufacturing.com/api/v1

Authentication & Scopes

Authenticate all API requests by providing your secret API Key via the x-api-key HTTP header or as a Bearer token in the Authorization header.

Example Header:
x-api-key: nkb_live_3f9a7c81d2...

Available Permission Scopes

products:read
Access catalog, product descriptions, pricing, and packaging details.
orders:read
View purchase orders, item lines, production tracking, and order statuses.
orders:write
Create and submit new purchase orders programmatically.
deliveries:read
Track Delivery Receipts (DRs), vehicles, drivers, and client acceptance.
invoices:read
View sales invoices, balances, due dates, and payment history.
inventory:read
View finished goods stock and converted raw material requirements.
GET /api/v1/products Scope: products:read

Retrieve list of active cosmetic products with pagination, search, category filter, and client-specific pricing.

curl -X GET "http://my.nkbmanufacturing.com/api/v1/products?limit=5" \
  -H "x-api-key: YOUR_API_KEY"
const res = await fetch("http://my.nkbmanufacturing.com/api/v1/products?limit=5", {
  headers: { "x-api-key": "YOUR_API_KEY" }
});
const data = await res.json();
console.log(data);
import requests

headers = { "x-api-key": "YOUR_API_KEY" }
res = requests.get("http://my.nkbmanufacturing.com/api/v1/products?limit=5", headers=headers)
print(res.json())

                    POST
                    /api/v1/orders
                    Scope: orders:write
                

                
Programmatically submit a Purchase Order with line items. Automatically calculates custom pricing and assigns transaction-safe PO-YYYY-XXXXXX numbers.


                

                    

                        

                            
                            
                            
                        

                    

                    

                        
curl -X POST "http://my.nkbmanufacturing.com/api/v1/orders" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "tolerance_percent": 10.0,
    "billing_policy": "ACTUAL_DELIVERY",
    "form_of_payment": "30 Days Net",
    "notes": "Automated order via REST API",
    "items": [
      { "sku": "SKC-2026001", "target_quantity": 500 }
    ]
  }'

                        
const res = await fetch("http://my.nkbmanufacturing.com/api/v1/orders", {
  method: "POST",
  headers: {
    "x-api-key": "YOUR_API_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    tolerance_percent: 10.0,
    items: [{ sku: "SKC-2026001", target_quantity: 500 }]
  })
});
const data = await res.json();
console.log(data);

                        
import requests

payload = {
    "tolerance_percent": 10.0,
    "items": [{"sku": "SKC-2026001", "target_quantity": 500}]
}
res = requests.post("http://my.nkbmanufacturing.com/api/v1/orders", 
                    headers={"x-api-key": "YOUR_API_KEY"}, 
                    json=payload)
print(res.json())
